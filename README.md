# Moonrabbit —— 通用多角色 RP 界面

> 仓库名：`moonrabbit`（月兔：多角色同台的月光剧场）

> 🤖 **AI 辅助项目**：本项目由 AI 辅助开发与维护（代码审查、文档、测试均由 AI 协作完成）；它同时也是一个 AI 辅助创作工具——用任意 LLM API 驱动多角色互动小说。欢迎其他 AI 开发者 / 人类开发者一起改进。

一个**零 npm 依赖**（纯 Node 内置模块，仅需 Node ≥ 18）的多角色互动小说 / 角色扮演聊天界面：AI 按「角色名：台词」分段输出，界面自动渲染为头像 + 气泡。支持任意 OpenAI 兼容 / Anthropic 兼容端点。

## 快速开始

```bash
# 需要 Node.js ≥ 18（用了内置 fetch / ReadableStream）
node server.js        # 或双击 start.bat（仅 Windows）
# 打开 http://127.0.0.1:3081
```

> 启动脚本 `start.bat` 为 Windows 专用；macOS / Linux 上请直接 `node start.js`（自动探测空闲端口，从 3081 起）。

首次使用：点击右上「⚙ API」配置端点（协议 / Base URL / API Key），保存时自动探测验证。

## 功能

- **多角色渲染**：`角色名：台词` / `角色名（动作）` 自动分段，头像 = 首字徽章（按名字哈希取色，任意角色名即用）；角色档案可上传**自定义头像**（本地文件，圆形小图显示）；也可 **🎨 生成头像**——给一张参考图，按图生图产出一张脸部特写头像（引擎、端点与 Key 复用下方「AI 场景插图」那一套配置，不另设开关；需先配置生图服务才可用）
- **世界设定**：右侧文本框填写世界观 / 角色卡 / 规则，随对话注入 system（保存在浏览器 localStorage）
- **群聊模式【未经测试 · 实验性】**：多角色各自**独立调用模型**发言（不是一次生成全员台词）——「导演」先调度本轮由谁开口，然后按顺序逐个发言，**后发言者能看到前发言者的实际输出**，形成真实反应链；支持 `@角色` 点名与 `@旁白`、名单可禁言 / 限句数。⚠️ 该功能虽按设计实现，但**尚未充分测试**，行为与接口可能变化；且**默认关闭**，需在会话中显式创建 / 开启（「＋ 群聊」按钮或侧栏面板），不影响普通单脑对话
- **会话管理**：新对话 / **档案（隐藏）** / 恢复 / 删除（`data/chats/`）；每条会话右上「📦 归档」隐藏，侧栏底部「已归档 (N)」折叠分组可看 / 「♻️ 恢复」。**刷新 / 重开浏览器（或桌面壳）会回到上次打开的那条对话**——优先读浏览器记忆，读不到时回落到服务端记下的「最后会话」（桌面壳的 WebView 里 localStorage 可能不落盘，靠这一层兜底）
- **剧情记忆**：AI 回复末尾的 `<storyevent>` / `<items>` / `【更新】` 标签自动记账 → 时间线 / 物品栏 / 情绪 / markdown 导出（`data/turns/`）；AI 在新地点首次造访时输出 `location_detail`（分组|地点名：详细描写），侧栏「地点档案」页签可查看 / 手动追加 / 导出（含 2 句物理特征 / 氛围 / 历史痕迹，知识库格式可直接复用）
- **情绪追踪**：AI 可在 `<storyevent>` 内输出 `emotion: 角色=情绪` 自动记录各角色当前情绪，侧栏「情绪」页签可查看/手动修正；情绪注入 system 帮助 AI 保持情绪连续（不前一秒哭后一秒笑）
- **历史检索**：本地关键词全文检索全部历史消息（零 API，多词空格 = AND，命中高亮，可展开全文）
- **agent 助手【未经测试 · 实验性】**（可选，按需开启）：侧栏「🎬 导演台」——对 agent 说一句话（补设定／给导演意图／指出偏差），它分类归档并在下一轮按需注入；配套「禁忌」区（指出偏差 → 出修正草案 → **确认后**才生效，生效的禁忌每轮强制注入）与 4 具**只读**工具（读回合记录／语义检索旧剧情／读设定条目／看本轮已注入）。⚠️ 该功能虽按设计实现，但**尚未充分测试**，行为与接口可能变化；**默认关闭**，开关在「⚙ API → agent 助手」，关闭时 prompt 与未开启前完全一致
- **语义检索【未经测试 · 实验性】**（可选，按需开启）：侧栏「🔍 语义」页签——**按意思**找旧剧情（搜「吐露心事」能召回「告白」段落），弥补关键词检索搜不到近义表达的缺口。索引内容＝事件时间线＋对话原文＋历史摘要；索引与查询走 **OpenAI 兼容 `/embeddings` 端点**（端点 / 模型 / Key 都可在「⚙️ 设置」里填，默认可接云端服务、也可指向本地 embedding 服务），**默认关闭**，未配置不影响任何其他功能。可开「自动注入」：每轮用你的输入语义召回相关旧剧情给 AI 参考（会有少量 embedding 调用）。⚠️ 该功能虽按设计实现，但**尚未充分测试**，行为与接口可能变化
- **自动压缩总结**：历史超阈值（默认 80000 字符）自动把最旧一半压成摘要，缓存复用（`data/summaries/`）
- **辅助 API**：⚙ API 弹窗可配置独立辅助端点（协议 / Base URL / Key / 模型 / 回退开关）——自动摘要、联网搜索等后台任务走辅助端点，不抢主对话 API；请求串行排队防 429；辅助失败默认不回退主端点（可手动开启）
- **视角切换**：输入区上方切换叙事视角（默认=用户角色主观视角，可自定义角色名），注入 system + 记账
- **换装**：侧栏提交角色着装变化，注入 system + 记账
- **扩写指令**：输入区上方「✍️ 扩写」胶囊开关——开启后，简短指令（如「角色去厨房」）会被自动扩写为详细的动作 / 场景 / 台词描写，注入 system + 记账
- **工具桥 · 联网搜索**：输入区上方「🔍 联网」胶囊自由开关；开启后当用户明确要求「联网 / 搜索 / 查一下」或需核实现实世界信息时，自动调用 `web_search` 工具，结果注入对话并要求标注来源（界面以 🔧 轨迹实时显示工具调用；开关状态按会话持久化 + 记账）
- **重roll / 删除**：AI 回复右上「↻」截断重发、「✕」删除
- **重roll 恢复旧版本**：重roll 后旧回复保留为「旧版本」气泡（虚线半透明），带「↩ 恢复此版」按钮——后悔了可一键换回，支持多次重roll 的版本链回溯（每版独立可恢复）；「✕ 删旧版」仅移除对比气泡不影响对话
- **分支（从某条消息分叉）**：任意消息悬停点「⤵」即可从该条分叉出新会话——新会话继承分叉点之前的全部消息、**剧情记忆**（时间线 / 物品栏 / 情绪都由回合记录派生，同步复制）与**会话常驻设定四槽**；原会话原样保留，两条线可分别继续，互不影响
- **手动附加资料**：侧栏「📎 手动附加资料」——粘贴剧情原文 / 设定补充等，发送下一条消息时随 system 的「## 补充资料」段注入一次，不进对话历史、用完即弃
- **会话常驻设定**：侧栏「📌 会话常驻设定」——写入本会话「每轮必读」的设定速记（不会被上下文裁剪 / 摘要压缩），每轮注入 system 且优先级最高（与「世界设定」冲突时以此为准）；按会话隔离、持久化，切会话自动加载；用于长线剧情防 AI 遗忘关键设定
- **设定触发器（Lorebook）**：侧栏「📖 设定触发器」——按关键词精确触发的设定注入（类似酒馆世界书）。每条含关键词列表 + 内容 + 优先级 + 常驻标记，命中关键词时自动注入；`tokenBudget` 控制注入量（auto=10% maxContext / 自定义 / 不限）。数据在 `data/lorebook.json`，可导入/导出 JSON。
- **世界书（多本 · 按会话启用）**：侧栏「📚 世界书」——比设定触发器更结构化的一套（**两者并存**，注入时合并为一条扫描链）：一本世界书＝一个文件（`data/worldbooks/<id>.json`），可建多本；每本可设 **scope=chat（按会话勾选启用/停用）** 或 **scope=global（所有会话默认生效，可用「⏸ 停用全书」全局关闭，也可在单个会话里取消勾选临时停用）**；书内条目分「**强制注入（每轮）**」与「**关键词匹配**（任一/全部关键词，字面匹配，每个关键词 ≥2 字）」，各条目带优先级；预算与总开关沿用设定触发器那一份设置（强制注入条目不受预算限制，其余按优先级截断）。数据在 `data/worldbooks/`（**开箱为空**，不预置任何内容；改书请走界面/API，手改 json 会被服务端内存态覆盖）。
- **会话排除指令**（写在会话常驻设定任意槽位）：`【排除设定触发器】`（跳过整条注入链——设定触发器与世界书都不注入，防剧情串线）——其他排除指令（排除当前状态/世界观/角色卡等）本版不支持（仅保留这一条控制）
- **API 采样预设（命名预设）**：⚙ API 设置里的「🎛 采样预设」——命名预设一键切换（内置「DeepSeek 默认 / RP 创作 / 省 token 快速」），可自定义保存 / 覆盖 / 删除；参数含温度 temperature、top_p、top_k、presence/frequency_penalty、输出上限、上下文预算（应用预设会覆盖对应字段）；持久化（`data/presets.json`），重启后沿用
- **对话编辑**：每条消息悬停显示「✏️ 编辑」（直接改内容，保存/取消）与「✂️ 截断」（删除该消息及其后所有——剧情跑偏时一键拉回正轨）；配合重roll/恢复旧版本/删除，完整覆盖对话管理
- **思考链显示**：模型思考过程折叠展示（可关闭）
- **统计栏**：轮次 / 调用 / 耗时 / 首 token / 缓存命中 / token 用量（按模型分桶）
- **峰谷提醒**：DeepSeek 官方直连端点 + 高峰时段（9-12 / 14-18 北京时间）自动提示 + 发送确认（可关闭）
- **主题 & 背景**：夜空 / 纸面 / 暖夜 / 森林 / **自定义调色板**（色相 / 饱和度 / 亮度滑杆 + 明暗模式）+ **背景图 URL**（自助美化，无需写 CSS）
- **新手导航**：首次使用自动弹出交互式导览（分区介绍 + 高亮 + 跳过）
- **快捷键**：输入框 `Enter` = 换行、`Ctrl/Cmd+Enter` = 发送；全局 `Ctrl+Shift+F` = 聚焦世界设定输入框、`Ctrl/Cmd+K` = 命令面板
- **命令面板（⌘K）**：顶栏「⌘K」或 `Ctrl/Cmd+K` 唤起——一次列出**全部卡片 + 常用动作**（新建对话 / 刷新会话列表），输入即过滤，`↑↓` 选择、`Enter` 跳转（自动切到卡片所在面板并展开）、`Esc` 关闭；纯前端、零后端
- **Markdown 渲染**：消息正文支持代码块（```）、行内代码（`）、引用（>）、无序列表（- ）、图片（`![描述](URL)`，粘贴剪贴板图片自动转 base64 插入，>1MB 拒绝）
- **会话导入 / 存档 / 搜索**：📥 导入 JSON 会话（与导出对称）；💾 存档点（快照 + 读档回滚）；🔍 对话内关键词搜索（高亮 + Enter 跳转）
- **多槽位常驻设定**：📌 会话常驻设定分「其他 / 背景 / 关系 / 规则」四槽编辑，按槽注入 system
- **移动端**：窄屏（<768px）侧栏自动变抽屉（右上角 ☰ 开合）
- **AI 场景插图（可选，按需开启）**：🎨 插图按钮 → 选风格 / 引擎（文生图通道）→ 输入或让 AI 生成提示词 → 渲染场景插图；「🎭 纯场景（无人物）」开关用 negative_prompt 排除人物，只出环境 / 背景（`server.js` 的 `sceneryOnly`）

## 数据文件

运行时数据全部在 `data/`（已 gitignore，不提交）：

```
data/chats/{会话}.json        对话全文（含标题/时间戳；群聊模式开关与名单也存这里）
data/turns/{会话}.jsonl       回合记账（时间线/物品栏/情绪数据源）
data/summaries/{会话}.json    自动压缩摘要缓存
data/model.json               端点配置（含 API Key 与辅助 API，勿提交）
data/stats.json               调用统计
data/op.json                  视角/换装/扩写/工具/会话常驻设定状态
data/worldbooks/{世界书}.json 世界书（多本，开箱为空；改书走界面，勿手改）
data/emotions.json            手动设置的情绪记录（回合内 emotion 标签聚合优先）
data/vec/{会话}.json          语义检索向量索引（按会话，点「建立/重建索引」生成）
data/vec-config.json          语义检索配置（含 embedding 端点/模型/Key，勿提交）
```

浏览器内的聊天历史刷新即清；跨会话接续靠「世界设定」文本 + 回合记录导出自行归档。

## 设计原则

- **零 npm 依赖**：核心仅使用 Node.js 内置模块（`http` / `fs` / `path` / `net`），**无需 `npm install`**；运行仅要求 **Node ≥ 18**（`fetch` 等 API 为内置）
- **零前端框架**：界面为纯原生 JS，无 Vue / React / 无 CDN 外链；主题、世界设定、会话数据全部本地存储（浏览器 localStorage + `data/`）
- **核心零外部服务**：检索 / 摘要 / 记账全部本地完成；**只有 LLM 对话**走你配置的端点
- **可选外部服务（按需开启）**：联网搜索（`web_search` 工具）、AI 场景插图（`/images/generations`）、TTS 语音、语义检索的 embedding 端点等为**可选增强能力**——**端点、模型、Key 全部由你自己填**（软件不内置任何厂商端点，也不会去读你机器上的任何配置文件），由用户显式开启才使用，未开启不影响核心功能，且**均为运行时 HTTP 调用而非 npm 依赖**
- **内容与平台解耦**：不内置任何世界观 / 角色，一切设定由用户填写
